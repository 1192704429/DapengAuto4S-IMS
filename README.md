# 基于 SpringBoot + Vue.js 的大鹏汽车4S店信息管理系统的设计与实现

> 本文围绕大鹏汽车4S店的日常运营管理需求，基于 Java SpringBoot + Redis + Vue.js + ElementUI 技术栈，设计并实现了一套支持多角色、多层级数据权限的信息管理系统。

## 一、项目背景

- 大鹏汽车4S店在日常运营中面临客户信息分散、维修流程不透明、配件库存管理混乱、财务核算困难等问题。
- 传统的纸质或单机管理模式难以支撑多角色协同作业，无法满足系统管理员、客服人员、维修工程师、财务人员之间的数据流转与权限控制需求。
- 本文设计的信息管理系统通过统一平台实现了客户管理、车辆档案、维修工单自动派单、配件出入库、财务结算及数据可视化统计等功能，显著提高了4S店的运营效率和管理的规范性。

## 二、功能模块介绍

- 系统采用 B/S 架构，分为前端展示层和后端服务层。
- 系统支持4个角色，不同角色拥有不同的菜单与数据权限。

| 角色 | 所属端 |
| :--- | :--- |
| 系统管理员 | 管理端 |
| 客服人员 | 接待端 |
| 维修工程师 | 维修端 |
| 财务人员 | 财务端 |


![功能模块图](docs/images/01-func-module.png)

## 五、主要业务流程

1. 系统管理员登录后，创建系统中的不同角色信息，维修人员需单独设置工时费字段。
2. 系统管理员管理供应商、维修项目分类、配件分类等基础数据，并查看车辆、维修记录、订单信息，以及财务类和维修类的数据分析图表。
3. 客服人员登录后，为来访的维修车主添加车主信息，并创建维修订单（需记录基本车辆问题）。
4. 系统自动将维修工单派发给空闲的维修工程师。
5. 客服人员可实时查看维修状态与进度。
6. 维修工程师登录系统后，查看系统派给自己的工单，进行判断并处理。
7. 维修工程师添加维修详情，包括维护本次维修使用的配件、填报具体工时以及填写维修报告。
8. 维修工程师对配件进行入库操作，该操作产生系统的支出记录，财务人员可查看。
9. 财务人员登录后，对已完成维修的记录生成结算订单，并对订单进行管理，订单包含收入与支出两种类型。

## 六、项目拓展性

- 可扩展接入微信小程序或移动端，方便客户在线预约维修、查询车辆维修进度。
- 未来可引入消息推送机制，当工单状态变更或库存低于预警阈值时，系统自动通知相关人员。
- 可扩展对接第三方支付平台，实现线上结算功能。
- 基于现有数据统计分析模块，可增加AI预测功能，用于预测配件需求量或维修高峰期。
